# 美术与 UI 文件归档约定

- 用户已指定 `F:/work/millionnaire/design/screens/` 为素材、图片、UI 设计和相关记录的统一目录。
- 后续新增或确认的背景、图标、头像、按钮、卡片、整页效果图及动效分镜，直接保存到该目录的对应子目录；不要新建外层 `design/assets-vN` 或 `design/ui` 作为存放入口。
- 保留分类：`screens/assets/`、`screens/assets-v2/` 等为素材方案，`screens/ui/` 为版本设计稿与提示词，`screens/records/` 为来源及校验记录。后续素材方案子目录也必须位于 `screens/` 内。
- 候选与历史版本保留，不因归档就标记为已确认或已接入游戏。新增独立素材应在方案清单中注明状态。
- 版本稿完成后运行 `screens/records/update.ps1`，同步根目录查看图；该脚本只读取 `screens/` 内的稿件。
- 更新 `screens/README.md` 和相关来源记录；向用户提供 `screens/` 内的完整路径。
- 不删除旧目录原件，不覆盖用户确认的素材或无关工作；素材归档不包含修改游戏代码的授权。
- screens顶层查看图使用“二位序号-具体中文界面名称.png”，例如“01-对局棋盘-普通回合.png”；序号仅用于排序，不能代替名称。ui版本原稿使用“具体中文界面名称-vN.png”。历史稿已有描述性名称可保留。
- 当前查看图同步最新对应版本；风格历史参考在名称中标明。旧查看图存入ui/history并保存来源／重命名记录，不与当前图混放。重命名同时更新当前索引、脚本和引用。
