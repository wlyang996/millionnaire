## 设计目标

1. 自己的位置容易辨认：完整小人物棋子、蓝色底座与选中环、头顶指针、`我 · 糖糖` 标签，与顶部本人卡片使用相同角色；提供“定位我”。其他玩家采用不同角色和底座颜色；同格时需错位排布。
2. 棋盘有完整视觉设计：清晰地产格边界、柔和分类色条、小镇内景、房屋与特殊地点图标；中央提示缩小，避免遮住大部分地图。所有角色位于格子和建筑之上，移动时保持可见。
3. 单颗六面骰子有动作：准备、抛起、翻滚、接触地面、轻回弹、最终停稳。最终点数显示明确；旋转和光效只是表现，不重新生成游戏点数。
4. 人物逐格跳：短暂蓄力、起跳、腾空、下落、落地压缩、回弹，完成当前格的落地再跳下一格；影子随高度变化，落点用轻微尘点/波纹反馈，不使用整段直线滑行。

## 动效参数候选

骰子先以约 1.2 秒、每格跳跃约 250ms 作为体验评审的建议，尚未确定正式时长，也未修改现有配置。移动 4 格用 4 次独立起落；正常移动结束后才进入落点处理的视觉阶段。
移动时建议柔和跟随当前行动棋子；用户手动拖动后可用“定位我”找回自己。多人同格需保留本人标签，避免棋子相互遮盖。

## 使用边界

这是静态设计与动画分镜，不是已实现的动态效果。格数、格子类型、资金、点数和实际移动路径仍以当前规则及对局结果为准；AI 概念图不作为棋盘配置来源。现有 50 格环形布局为 12 列×15 行的外圈（角格只计一次），需要在正式实现时精确落实。
本张整页图尚未严格还原 50 格数量，也存在部分玩家头像重复、头像与昵称配对不准确的问题；它用于评审棋子可见性和整体美术，不作为玩家身份或地图数据的实现依据。
先评审棋盘可读性、人物大小与动作方向，再决定资源拆分和实现；既有素材方案 A/B 仍保留，未在本次选定。
