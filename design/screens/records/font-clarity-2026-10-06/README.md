# 棋盘土地名清晰度修正

用户指出棋盘字体模糊，土地名尤其明显。本轮仅修改客户端棋盘文字显示。

原因：原先土地名以约12字号生成贴图后，随父格子的非等比缩放和棋盘纵横比缩放而变扁、被拉宽；引擎TTF栅格化依据view缩放，不补偿这些父节点缩放，字形精度不足。

修正：土地名以3倍字号和文字框生成贴图，文字节点反向缩放；抵消父格子及棋盘的非等比伸缩，使最终字形保持等比。按照文字框宽高预先计算字号，不再依赖SHRINK反复缩小。两侧名称区略加高，图标仍位于名称上方，命中区与棋盘规则不变。

验证：Cocos Creator3.8.8类型检查和web-mobile构建通过；30格／50格浏览器预览检查文字完整显示。截图为桌面浏览器预览，不代表微信真机验收。棋子或气泡覆盖土地名属于原有遮挡，与文字截断不同。

- `board-50.png`：50格整页预览。
- `tile-names.png`：同页顶部名称区截图。
- `board-30.png`：30格整页预览。

未替换字体、美术素材或游戏规则；其余正常字号文字未进行全局高倍栅格化，避免增加整页贴图内存。
