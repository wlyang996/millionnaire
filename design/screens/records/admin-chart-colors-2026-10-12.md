# 运营看板图表配色修正

日期：2026-10-12。来源：用户反馈的线上看板截图与当前源码。状态：源码及网关静态产物纳入概率、规则预览与动效补齐的同一提交；用户已授权推送 `origin/prod`，实际部署结果待确认。

## 原因与修改

`AdminChart.vue` 覆盖所有图表的色板，统一以紫色开始；`DashboardOverview.vue` 将分类按数量降序排列，导致每张环图的最大类别总是紫色，分类颜色也会随名次变化。

- 分类颜色按后台 API 原始键固定，不按数量、输入顺序或中文标签分配。
- 结束方式：限时紫色、破产橙色；结束原因：全员挂机珊瑚红、只剩一人蓝色、时间到金色等。
- 地图：30格青色、50格粉色；人数：2人蓝色、3人金色、4人绿色等。
- 抽卡与幸运/不幸格共用事件语义颜色：现金奖励绿色、现金罚款红色，其余类别区分显示；道具采用14色色板。
- 图表组件接受调用方的自定义色板；未知新类别按原始键计算稳定颜色。
- 单类别环图仍使用一种颜色；保留真实次数、排序、占比与空数据状态。

## 验证

- `npm test`：7项通过，新增覆盖排名颠倒、类别缺失、中文标签变化后的颜色稳定性，以及 ECharts SVG 实际渲染的跨图颜色区别。
- `npm run build`：通过，静态构建产物已更新至 `gateway/src/main/resources/static/admin`。
- 未修改统计接口、后端Java、玩法参数或数据库迁移。本次未做线上部署与浏览器视觉验收。
- 配色实现依据 [ECharts 官方样式文档](https://echarts.apache.org/handbook/en/concepts/style/) 的 `color` 和 `itemStyle.color`。没有新增美术素材或版本设计稿，本轮无需刷新顶层设计查看图。
