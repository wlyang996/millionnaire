# 外围土地再次扩大

用户要求中间区域再缩小、外围土地再扩大。`BoardLayout.boardAxis` 外围带由1.5倍基础格宽调整为1.8倍，厚度增加20%。棋盘总宽高和格子数量保持不变，内圈间隔相应压缩。

中心背景、土地节点、点击映射、棋子落点、移动路径与牌堆偏移继续共同使用同一组轴坐标，保留上一轮土地名的高精度等比文字。
