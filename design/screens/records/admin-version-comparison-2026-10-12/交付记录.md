# 历史版本对比与回滚摘要

日期：2026-10-12。用户授权实现历史版本对比。本次源码、测试及网关静态构建产物已更新，本地验证通过，纳入本次提交；用户已授权推送至 `origin/prod`，实际部署结果待确认。

## 实现范围

- 版本中心默认选择最近历史版本与当前生效版本，也可任选两个历史版本、交换对比方向；包含内置默认配置。
- 仅展示变化项，按玩法分组，可筛选；显示中文字段名称、旧值、新值、金额 / 秒 / 毫秒 / 轮次等单位及开关状态。
- 事件、道具、幸运、不幸、起点三选一和城市事件分别计算奖池占比。权重未变化但占比受到其他项目影响时，展示“概率联动”；变化用百分点表示，保留最多四位小数。
- 城市事件占比明确为已启用事件池内的比例，实际触发仍受玩法开关、模式和触发概率限制。
- 人物以外的规则列表按稳定的类型标识对齐，避免调整数组顺序产生虚假差异；逐格地名、组号、等级租金和排名积分保留具体位置。
- 对历史快照缺失的字段显示“未设置（按服务端兼容规则）”，不把编辑区补值写回历史快照，不隐藏新增 / 移除项。
- 查看、切换、筛选和交换对比均不写入规则草稿。载入编辑仍沿用原来的覆盖确认。
- 回滚窗口先读取当前生效配置与目标历史配置，再展示差异；确认按摘要中的 `expectedActiveId` 调用现有回滚接口。409 冲突禁用确认，必须重新读取摘要；失败或取消保留草稿。成功后读取新生效版本和发布记录。
- 没有修改后端 Java、数据库迁移或任何生产玩法参数；继续使用现有鉴权、历史读取及回滚接口。

## 验证

1. `web-manage/npm test`：23 项通过，其中新增 7 项对比测试；覆盖独立奖池、概率联动、全零奖池、数组重排、新增 / 移除、旧快照缺项、枚举 / 单位和引擎称号指标。
2. `web-manage/npm run build`：通过，产物已生成至 `gateway/src/main/resources/static/admin`。最终入口为 `index-BN8Ua1JU.js`、`index-DpIHhBFH.css`。
3. 真实隔离本地后台：使用既有 `127.0.0.1:5182` 内存后台及 `5181` 静态代理，未连接生产。创建可丢弃版本 #3 修改起点权重、援助额度、时限及公告，页面展示 7 项差异、4 个玩法分组；其中道具原权重 40 保持不变，但概率联动随现金权重变化。
4. 实际浏览器检查通过：两个非生效历史版本 #4 与 #1 可对比；相同版本显示零差异；交换方向正确；玩法筛选可用。编辑公告草稿后跨页对比、取消回滚，名称“对比时保留的未发布草稿”及未发布标记仍保留。
5. 临时本地 `5183` 代理注入一次 503，页面显示读取失败，重试恢复 8 项差异。延迟读取 #1 3500ms 后立即选择默认配置，最终显示默认配置对比，旧响应未覆盖新结果。
6. 真实并发冲突：准备 #3 → #2 回滚摘要后，隔离后台另行发布内容相同的 #4；确认回滚收到真实 409，按钮禁用。重新读取后摘要变为 #4 → #2；取消仍保留草稿。
7. 真实本地回滚成功：确认 #4 → #2 后生成新版本 #5，发布记录及生效标记更新，规则草稿按窗口提示清除。仅操作隔离内存数据。
8. 390px 窄屏回归时 `clientWidth = scrollWidth = 375`，双列旧 / 新值未横向溢出；临时视口已恢复。窄屏检查发生于格式精度及字段名称补齐之前，布局 CSS 此后未变。最终桌面构建再次读取版本 #4 → #5 正常，默认历史版本选择正确，页面控制台无错误。
