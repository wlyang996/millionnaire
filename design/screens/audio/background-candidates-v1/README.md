# 背景音乐试听候选 v1

日期：2026-10-12。状态：三首均待用户试听，未确认、未上传COS、未接入客户端。

用户要求先生成几个背景音频审核，再接入游戏并支持后台配置。本轮默认按无歌词、无人物语音的纯音乐处理。

1. `01-晨光小镇-试听.mp3`：112 BPM，轻快明亮的木琴、弹拨和弦、低音与轻打击；建议作为大厅/普通棋盘的风格候选。
2. `02-河畔午后-试听.mp3`：84 BPM，柔和电钢琴与气息感旋律，节奏较稀疏；建议用于大厅或长时间对局。
3. `03-好友开局-试听.mp3`：108 BPM，俏皮玩具木琴、拨弦与轻柔沙锤；建议用于活泼的好友桌游风格。

来源：本项目原创音符编排，由 `generate.py` 使用numpy程序合成音色，再用已有FFmpeg编码为128kbps、44.1kHz、单声道MP3。不是AI音乐模型生成、不是实际乐器录音，不使用外部歌曲或采样。当前工具没有AI音频生成模型，已向用户说明此限制；合成音色是否合适由实际试听决定。

试听版有短淡入/淡出，不当作已验收的无缝循环母带。原始循环PCM在忽略的`tmp/audio-reference-analysis/background-candidates-v1/`内，可由脚本复现。正式采用时再验证长时间循环、MP3补齐和切换效果，不将试听曲自动上传发布。

检查：三个实际MP3均重新解码，检查时长、采样率、单声道、有限采样值、峰值与RMS；结果和SHA256见`manifest.json`。这些是技术检查，不等同于人工听感确认。

旧骰子合成稿及背景抑制失败稿保留历史，不使用其中任何混合音轨。游戏音效后续单独制作/获得独立母带，单独审核。

复现：使用带numpy的Python运行`generate.py --ffmpeg <已有ffmpeg可执行文件的绝对路径>`。脚本只在本项目的试听目录与忽略的临时音频目录写文件，不修改客户端。

后台和游戏音量接入计划见`web-manage/audio-management-plan.md`。本轮没有实施音频后台或新音量弹窗；审核曲目后再实施。
