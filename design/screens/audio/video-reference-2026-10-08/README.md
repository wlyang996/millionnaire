## 处理与代码备注

- 仅做解码、截取和两端2毫秒淡入淡出以减轻切口爆音；没有合成、改变音高、归一化、去音乐或AI分轨。
- 来自成片的混合音轨，可能含背景音乐和其他效果，不标为无背景的独立音效母带。两个主要片段已获用户试听认可。
- 本轮仅归档参考，未修改游戏代码。此前程序合成dice-v1已被用户否定，不作后续采用来源。
- 后续骰子声在骰子动画开始时触发一次；单格音效跟随每一格跳跃动作触发，声音间隔由实际动画控制，不重复播放整段六格录音来模拟任意步数。
- 成片来源记录不等于获得正式发布素材许可；当前作为用户指定的声音风格参考，正式上线前应确认素材授权或制作独立母带。

复现：inspect_video.py需要imageio-ffmpeg和Pillow；cut_audio.py仅使用Python标准库。clips.json记录切点、格式、峰值及各文件SHA-256。已检查帧数、格式；投骰及连续移动片段继承原解码音轨的0dBFS触顶，未加增益，不宣称原录音无削波。没有将工具检查称为实际听感验证。
