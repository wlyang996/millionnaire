2026-10-19。用户已采用 42／43 号情景卡布局，并要求继续补齐素材。本目录包含现有普通奖励 8 条、扣款 8 条故事各一张独立插画，共 16 张；单张美术待审阅，尚未接入客户端、后台或对象存储。

## 交付约定

- `reward/`：扶老过街、拾金不昧、义务植树、征文获奖、找回小狗、街头义演、幸运中奖、搬货帮忙。
- `fine/`：随地吐痰、闯红灯、乱扔垃圾、深夜喧哗、违章停车、踩踏草坪、图书逾期、打碎花瓶。
- 每个故事独立生成整张横向 4:3 不透明 PNG；没有从整页 UI 截图裁切。
- 图内不含 UI 标题、金额、按钮、进度条或卡框；交通标志、钟面刻度等场景符号属于插画内容。文字、金额与展示进度由后续实时 UI 绘制。
- 棕发蓝衣人物作为事件插画中的叙事角色，不表示必须替换为当前玩家头像。
- `storyIndex` 对应生成时 `client/assets/scripts/core/EventDraw.ts` 数组的零基顺序，仅作来源追溯；素材 ID 是设计标识，尚不是服务端事件 ID。
- 原始高分辨率文件用于美术归档。接入前需另行导出适合小屏的运行资源，并验证按需加载、缓存与内存，不能把 16 张原图加入启动全量预热。
- 本轮没有调整事件金额、概率、权重、停留时长或任何玩法参数；幸运／不幸的其他专属故事不在这 16 张范围内。

## 来源与验证

使用内置 `image_gen`，未使用 CLI。奖励、扣款分别以已经采用布局的两张候选稿作为画风参考，单独描述每个故事。完整提示词、生成文件来源和 SHA-256 见本目录记录。

逐张目视检查了主体、故事道具、构图与画风。文件检查结果：16 张均为 1448×1086（4:3）PNG，原图合计 35.61 MiB，16 个 SHA-256 均不同；16 条故事与当前数组逐字对应，审阅和说明页的 22 个本地链接均有效。`records/update.ps1` 同步校验通过，`git diff --check` 通过。尚未进行 Cocos 集成、小屏动态排版、帧率或真机验收。
