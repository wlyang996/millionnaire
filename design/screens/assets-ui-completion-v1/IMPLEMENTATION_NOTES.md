# 代码、交互与设计待办

本轮只补充素材；以下工作不能用生成图片代替。素材可用性、运行接入与流程完成度分别验收。

## 资源接入与排版

- 将本包单件复制到Cocos资源目录，登记ArtCatalog及同步工具；现有card_detail_background、detail_card_*、card_detail_rules_*槽位可沿用。新扁平按钮使用新资源键，旧按钮保留。
- 标题、规则板和按钮设置九宫格边距；聊天气泡须保留尾巴，消息长度动态撑开，不能直接把整张气泡横向压缩。
- 资产页按玩家头像标识选择八种information_host，不能始终显示蓝衣男孩。大卡名称和金额继续由文字层绘制；不把图片空白带误当缺失文字。
- 登录资料/大厅替换Logo和四人组合插画；结算换独立奖杯/桂冠/牌匾并保留真实排名。买地/升级/租金/交易、拍卖/欠款、弃牌/认输/战绩/房号输入的具体层级与布局仍需逐页对照03～18稿调整。
- 0级地产仍按既有规则显示未升级状态，不能为了匹配房屋近景把0级变成高级建筑；近景与等级模型可分开，但等级标签和租金必须真实。

## 动画

- 32张姿态是8角色×4帧的初始序列，需以相同角色帧画布和脚底锚点接入ready→crouch→airborne→land；逐格550ms、路径曲线、同格偏移沿用既有决定，不能加长业务操作窗口。
- 原图帧间仍可能存在轻微头部比例/手臂姿势差异；需在实际播放中校准缩放和锚点，不将静态预览视为连贯性验收。
- 当前骰子依然为位图翻滚。真实3D骰子需要立方体模型、点数面、材质灯光及落定动画，属于渲染代码/模型工作。同步结果应先由游戏状态确定，动画不能自行改变点数。

## 道具与经济流程

- 13/14目标选择页、合法目标提示、取消/确认、扣卡、每回合主动机会、响应保护与完整结算尚待接入。不能把Toast当成功使用；不能任意远程选地。
- 银行抵押/赎回需房产列表、现金检查、本金、手续费、抵押状态及结束办理窗口；监狱需判定/付费/出狱卡和剩余操作时限。素材不等于15稿流程完成。
- 虎口拔牙结果页需闭合者0/其他参与者500真实结果、双方视角、参与者清单和继续时机；人数动态、牙齿数=人数×2，禁止固定8/12/16颗。危险牙齿不应暴露。
- 特殊土地20～23/25的整体布局尚为候选：即使生成scene_*，也须在采纳布局后接入对应页；小镇入口是START土地，不是大厅。
