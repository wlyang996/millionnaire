更新原稿后，从项目根目录运行：

```powershell
powershell -NoProfile -File .\design\screens\records\update.ps1
```

脚本只读取screens内的已完成原稿，发布上述描述性文件名并核对SHA-256；不会重新创建旧英文顶层文件名。当前棋盘、动效和规范图按各自最新版本选择。其余当前来源在脚本中明确指定，新增版本时须一并修改条目和本索引。07是历史风格参考，18等展示方式仍是候选。旧外层design/assets*与design/ui只保留为历史原件。
