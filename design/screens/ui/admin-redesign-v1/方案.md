# 大富翁管理后台整改方案 v1

日期：2026-10-12。状态：用户已选择“彩光游戏控制台”布局并授权开发；本文保留设计阶段的规划，实际实现及验证见[开发交付记录](../../records/admin-redesign-implementation-2026-10-12/交付记录.md)。

## 推荐方向：彩光游戏控制台

以已接入登录页的紫色、橙色和几何角色作为品牌连续性，后台使用侧栏导航、彩光欢迎区、具有空间感的卡片和丰富的状态动画。浅色主题保留明亮的表单与数据区，深色主题使用深蓝紫底色与发光装饰。默认采用丰富动效，提供简化动效设置。

备选方向为“角色创作工作室”：横向导航、较大的角色展示区、紫橙色舞台背景，整体更像游戏内容创作工具。推荐“彩光游戏控制台”，便于承载当前较多的规则配置。

交互示意可切换总览、地图与玩法、人物工作室、版本中心，并演示悬浮、光球回弹、参数预览和人物选择。示意数字、版本、人物完整度均为演示值；人物用文字占位，正式稿使用项目现有原图。示意动效为本地 CSS/JS 表达，不代表已集成候选组件库，最终视觉与动效仍需按选定方向制作。

## 现状与页面分组

已核对 `web-manage/src/App.vue` 和 `CharacterManager.vue`：当前 Vue 3 + Vite + Element Plus，18 个标签页（迁移时更正原方案17个的计数）；管理端认证、规则校验/发布/历史/回滚、人物整套素材上传/目录发布与数据看板已存在。

新导航覆盖全部现有功能，分为六组：

1. 运营总览：数据看板。
2. 地图与经济：土地命名、同组地产、价格与租金、金额与固定费用、租金上涨。
3. 玩法规则：建房选项、事件与道具概率、起点三选一、轮次奖励、城市事件、结算称号、好友系列赛、组队合作、操作时限。
4. 人物工作室：人物素材。
5. 公告管理：公告。
6. 版本中心：发布记录、查看版本、回滚。

## 页面设计与动画

### 应用框架

侧栏分组、可折叠菜单、顶部面包屑和当前配置版本；未发布修改状态贯穿整个配置工作区。导航选中指示块采用弹簧移动，页面切换使用位移和透明度过渡，卡片分批进入。主题切换有扩散过渡，移动端导航变抽屉。

快捷搜索只检索本地配置项与页面标题。规则编辑底部操作区显示修改数量、校验、恢复和发布，跨页切换保留原有编辑状态。离开或退出时沿用必要的未保存修改确认。

### 运营总览

欢迎区使用低速极光、光球和轻量粒子；复用登录角色作为运营助手，加载、出错、成功时变换状态。核心指标为当前接口已有的对局数、参与玩家、新用户、平均时长和平均人数，按 7/14/30 天切换。

指标数字滚动，卡片鼠标聚光和轻微倾斜；对局趋势、分布图切换平滑变形，提示卡跟随指针。无数据库或无数据时真实说明原因，不展示伪造指标。现有统计接口没有实时在线人数，因此本轮方案不新增此类指标。

### 地图与经济

土地命名和同组地产：左侧编辑列表，右侧真实地图布局预览；选择某格时地图格子高亮、同组连线出现，名称输入同步更新。分组颜色与标签配合，选中地图格可定位编辑行。

价格与租金：档位卡片切换，升级等级预览、租金阶梯和价格修改前后对照；编辑数值时预览柱形或阶梯平滑变化。车站单独成组。金额与固定费用采用按业务场景分组的控件，并保留全部现有参数。

租金上涨：提供轮次—倍率曲线和参数联动，预览值按现有服务端规则等价计算，只用于说明；发布仍由既有服务端校验决定。

### 玩法规则

事件概率：事件权重与总计反馈联动，增加环形或堆叠分布预览；合法总计亮起完成指示，非法项标红并定位。幸运、不幸和道具分布各自独立。

建房、时限、系列赛与组队：场景分组和模式卡片，开关切换时相关字段展开；增加模拟房间设置摘要和组队关系示意。保留参数单位、默认值来源和依赖禁用行为。

起点三选一、轮次奖励、城市事件、结算称号：以游戏卡片、轮次轴、事件时间线和称号徽章展示，点击后编辑，预览与配置一致。动画联动由用户操作触发，不在输入框位置反复移动布局。

### 人物工作室

生效人物目录改成角色画廊，支持选中高亮、3D 倾斜与背景聚光。角色详情包含当前已支持的七项素材：普通头像、棋盘棋子、半身人物、递币、接币、欠款忧虑、托杯庆祝。

素材上传槽位从空到完成有过渡，上传进度、失败重试与七项完整度可见；切换姿态采用交叉淡入与轻微弹簧。区分草稿、已发布、停用、客户端默认与 COS 整套素材；保留完整套发布和本地备用人物规则。发布素材成功后才显示庆祝，不提前表示成功。

### 公告与版本中心

公告：输入内容时同步显示游戏内公告预览；开关和更新时间有清晰反馈。

版本中心：按时间线展示发布记录，当前生效版本有光轨强调；展开显示配置变化摘要，回滚前显示目标版本并确认。新发布流程依次显示变更摘要、校验、确认、请求执行和结果；真实接口成功后短暂庆祝。规则配置与人物目录分别展示版本，使用各自既有接口，不伪装成一次原子发布。

## 组件选型

- Element Plus：保留现有表单、表格、上传、弹窗和校验能力，通过设计令牌与局部皮肤统一外观。
- Art Design Pro：借鉴导航、主题、布局和页面编排，按需复用经核查的代码；不整套替换工程或引入其配套 Java 后端。官方前端为 Vue 3 / TypeScript / Vite / Element Plus / Tailwind CSS，MIT。
- Inspira UI：主选。按需复制源码，候选为 Card Spotlight、Border Beam，以及目录中的数字动画、3D 卡片、极光/粒子组件。官方仓库 MIT；具体名称、依赖、移动端表现和许可证在实际接入前逐项核对。
- Vue Bits：候选补充，用于 Aurora、Orb、Profile Card 等强视觉效果。当前许可为 MIT + Commons Clause，允许作为应用/网站/产品的一部分使用并需保留版权许可，限制销售、再许可或重分发组件本身；接入时保留完整说明。
- Motion for Vue：统一页面、列表、弹窗、共享选中块和交互弹簧；优先使用基础能力。
- Apache ECharts：替换当前手绘柱形和分布条，承载数据图表与规则预览。

按每个选中组件的依赖引入 Tailwind CSS、VueUse、motion-v、ogl 等，不把整个演示网站装进后台。确保样式预设不覆盖现有 Element Plus 表单；WebGL 背景按页面懒加载，卸载时释放资源。

## 动效规范

这是 UI 动效规范，与游戏玩法参数无关；实施时集中在前端主题/动效配置模块中，避免分散常量。

- 交互反馈：建议 120～220 ms。
- 页面、抽屉和列表过渡：建议 250～450 ms。
- 成功庆祝：建议 600～1,000 ms，完成反馈立即可见。
- 背景：低速持续运动，粒子与光球仅在可见区域运行；切换页面或后台标签时暂停/清理。
- 提供丰富、标准、简化三档动效偏好；默认丰富。尊重系统减少动画偏好，触屏提供等价点击反馈。
- 悬浮倾斜建议不超过 4～6°，输入中的表单保持位置稳定。发光、连线、浮动主要作用于导航、预览、角色和状态装饰。

## 实施顺序与验收

1. 公共框架：设计令牌、主题、导航分组、页面转场、动效管理、现有业务组件拆分。
2. 视觉样板：运营总览与人物工作室，实现主视觉、指标动效、角色与素材交互。
3. 全部规则页：逐项迁移现有参数，增加地图、租金和概率预览；确保所有读写字段与单位一致。
4. 公告与发布：预览、变更摘要、校验定位、发布与版本时间线。
5. 验证：全部现有功能可达；跨页草稿保留；人物上传/预览/发布和配置发布/回滚不回归；失败不展示成功；窄屏、两种主题、动效降级、动画资源释放；执行前端构建并更新网关静态产物。

本轮工作量主要在前端。优先复用已有接口；如发现字段或版本差异资料不足，先在方案记录限制，再单独明确需要的后端补充。当前仅完成源码与官方文档层面的选型，没有证明所有候选组件与项目版本已经兼容。
