## 以原版为准

原版AdminShell.vue已经使用@lucide/vue组件，navigation.js定义分组和菜单，controlColors.js及control-colors.css定义模块配色。本轮从这些源码读取配置，直接使用相同系列与名称的Lucide图标，不用图像生成工具重画SVG。

- 运营总览：Orbit，紫色淡底。
- 地图与经济：Map，琥珀淡底。
- 玩法规则：SlidersHorizontal，蓝色淡底。
- 人物工作室：UsersRound，玫红淡底。
- 声音工作室：Music2，青色淡底。
- 公告、版本、运营工具、系统管理保留当前源码的图标与颜色。

分组图标外框24px、内图形约16px，子菜单使用5px彩色圆点；不要把每一项都换成大尺寸灰色立体图标。保留折叠箭头、缩进和柔和的模块色选中背景；菜单文字保持可读，颜色不代替文字。品牌恢复原版紫色Gamepad2标识。

清爽白底与浅灰层次继续采用v6；任务工作台布局沿用v5的待办、草稿、版本和常用入口；交互节奏沿用v4，不额外加图表或修改业务功能。导航评审展示当前配置的9个分组，正式后台仍必须按账号权限过滤，不以本样机判断账号的访问权限。
