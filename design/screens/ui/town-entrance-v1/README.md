# 小镇入口／游戏大厅候选 v1

前轮将“小镇入口”误解为游戏大厅而生成此稿。用户随后明确指棋盘上的起点土地；本稿仅保留误解产物记录，不代表采纳或本次请求交付，正确稿见../start-tile-v1/。未修改客户端大厅代码。

沿用河湾小镇和四位好友的视觉，标题为“好友桌游”，副标题“小镇入口”。页面包括头像/昵称、声音/设置入口、四人桌游场景及四个既有功能：创建房间、房间号加入、返回对局、我的战绩。返回对局仅在存在可恢复对局时显示；示例房间826315不是固定数据。

布局采用上方小镇场景，下方清晰操作区：创建为黄色主按钮，加入为蓝色主按钮，返回对局为浅色次级行，战绩为底部次级入口。标题和按钮不得遮挡实际微信胶囊安全区。

使用内置image_gen，以第23张稿作美术风格参考，完整提示词保存于jobs.json。不是棋盘“起点”格的详情页，也没有新增小镇经营或商店玩法。原大厅两套风格参考仍保留，最终方案待用户选择。
