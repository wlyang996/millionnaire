# 小镇入口：起点土地详情候选

用户截图明确“小镇入口”是棋盘的起点土地（LAND_NAMES.md已有定义），不是游戏大厅。本稿针对当前格子详情中使用通用房屋、显示“无主”、下方仅一行文字的问题，设计独立起点详情布局。

上方展示专用入口桥与城门近景；中部使用“小镇入口／起点／特殊土地”身份卡及金币1000的规则说明；下方列出领取限制，底部关闭。起点不显示产权、原价、升级、抵押或租金表，也没有手动领取按钮。关闭页面不会触发奖励。

奖励按requirements.md第5节和既有规则：正常前进经过或停在起点1000，开局不领；定点移动只在落起点领奖；后退与送监狱途中不领；每回合最多一次。
