## 本轮调整

保留v2暖米灰与奶白配色，降低阴影强度，减少面板凸起，取消大卡片的悬停浮动。布局不会因菜单选中、数字变化或待办展开而移动；卡片详情使用预留空间。

1. 实体按键：悬停不浮起；按下只下沉1px，约140ms响应，松手平滑恢复；当前项保持内阴影和指示灯。
2. 旋钮：拖动时直接跟手，不排队追赶；音量按1%吸附，数值和外圈同步；保留数字输入与方向键。释放后不做过冲回弹。
3. 开关：默认220ms单次缓动，滑块停止于目标位置；图标与开关颜色同步变化，文字区域预留宽度。
4. 机械数字：默认约290ms逐位滚动，位间延迟12ms，结束不回弹；当前滚动未结束时忽略重复演示点击，避免重启动画造成跳动。
5. 抽拉卡片：拖动显示位移带阻尼，后方卡片仅小幅跟随；显示位移达到56px展开，未达到时220ms归位，无摇晃。保留点击、键盘展开入口。

统一缓动为 cubic-bezier(.22,.75,.25,1)。支持系统减少动态效果与评审页复选框；开启后按键、开关和数字直接更新，抽拉保留阈值判断。可选设计调节面板提供动作时长和阴影强度，不增加业务配置项。
