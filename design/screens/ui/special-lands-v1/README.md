# 特殊土地独立UI布局 v1

2026-10-06，用户要求生成游戏中心、银行、监狱及其他特殊土地的独立布局。此目录为静态候选设计，尚未采纳或接入客户端。按7种特殊土地分为4张双页效果图；普通地产不在本轮范围内。

- 银行：抵押和赎回独立状态，场景为河湾银行与柜台；上方现金、双标签、房产列表、单项选择及确认/结束办理。原价100%抵押；银行赎回手续费0；抵押不收租。
- 监狱：看守所与人物场景，显示失败次数、判定骰、掷骰/500出狱/出狱卡三项合法操作。偶数释放、第三次失败自动释放，释放后另投移动骰。
- 游戏中心：虎口拔牙专用场景，参与者与本轮倒计时、可点击牙齿区域；不设额外下注或入场费。牙齿数必须动态为参与人数×2，超时由服务器代选。触发闭合者0，其余参与者各500。
- 事件：本人中央问号卡背直接点击抽取；左上展开牌堆仍在，骰子保持中央位置，无“抽取事件”独立按钮。五类结果沿用第12张事件卡稿。
- 休息区：安静河畔场景及停留信息，无收租、额外奖励或跳过下一回合机制。“返回棋盘”只用于信息页关闭，不新增落点决策。
- 起点：起点门与经过领奖提示。正常前进经过或落在起点+1000，每回合最多一次，开局不领取；定点移动只在落起点领奖；后退与送监狱路径不领奖。图中“返回棋盘”仅关闭信息页。
- 车站：专用站台近景、产权和抵押状态、原价1000、有效车站数量×200的租金表；不显示普通地产升级按钮。示例表只列1–4座，50格地图可有6座，应按实际数量动态扩展。

数值、姓名、失败次数和示例房产均为排版示例，运行数据不得写死。规则依据：根目录requirements.md第5/11/12/13节、RuleConfigs.defaultV1、EconomyConfig、TurnModule及EconomyModule。

图中的系统时间/电量仅为设备样机装饰，实际微信小游戏不得绘制这些控件，标题区域应按真实胶囊安全区排版。图片字形与数量不代替上述定义；候选稿供风格和布局选择，实施时统一真实文字层与动态控件。

`jobs.json` 保存内置image_gen完整提示词及风格参考；原图和归档校验记录保留。后续需要从独立美术素材搭建页面，不能把完整效果图当作运行界面背景。
