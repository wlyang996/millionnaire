## 道具栏

- 单排，不换行；默认视口容纳 5 个完整道具项。超过 5 个显示项时左右滑动查看，右侧渐隐/滑动指示表达还有内容。
- 保留当前同类道具分组与数量角标。没有的道具不补成已持有项；不足 5 项按实际持有显示。
- 默认可见 5 项是 UI 容量，不是每局发 5 张，也不是修改持牌上限。当前规则正常最多持 6 张，右上角总量显示仍按真实总张数，如 6/6。
- 效果图示例首屏：免租、建造、拍卖、定点移动、路障；横滑后示例：建造、拍卖、定点移动、路障、出狱。这个顺序仅用于展示，不规定发牌或排序规则。

## 地名纳入地图 UI

- 采用 `../../LAND_NAMES.md` 的河湾小镇街区体系：50 格 28 块普通地产，30 格 16 块普通地产，全部不同名字。
- 三字地名放在格子下部，人物/小房屋占上部，底色条和归属标记各自保留，不用金币图标代替地名。
- 格子、点击详情、资产列表和交易/拍卖中的名称应一致。UI 名称定义按当前 `BoardLayout.ts` 同档地产的出现顺序分配，不移动地块类型、档位或拍卖标记。
- 完整 30/50 格位置与名称见 `map-ui-definition.json`，是设计定义文件，当前应用没有读取它。
- 50 格 12 列×15 行的外圈共 50 格；30 格 8 列×9 行的外圈共 30 格。定义中的所有普通地产名字已核对无重复，低/中/高数量分别为 10/10/8 与 6/6/4。

## 本局剩余时间警示

警示对象是顶部的本局倒计时，不是中央“轮到你了”的每回合操作时限。房间号、玩家昵称和现金不随倒计时变红。

- 剩余时间 ≥ 10:00：正常深色文字和时钟图标。
- 03:00 ≤ 剩余时间 < 10:00：时间文字和时钟图标红色常亮。
- 00:00 < 剩余时间 < 03:00：时间文字和时钟图标红色闪烁。
- 恰好 10:00 正常；09:59 进入红色常亮；恰好 03:00 保持红色常亮；02:59 进入红色闪烁。
- 闪烁节奏建议约 1 秒一周期，红色透明度 100% 与 35% 交替，仍可读。周期和淡化比例是动效建议，用户尚未指定精确数值。
- 到 00:00 后设计上停在红色常亮，最终对局结束状态以实际对局为准。
