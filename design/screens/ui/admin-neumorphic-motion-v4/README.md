## 节奏调整

1. 按键保留轻微悬停与按压，阴影使用一致的外阴影/内阴影列表渐变，避免直接切换阴影类型时突变；按下约100ms，松手约160～180ms。
2. 旋钮显示位置采用连续小数，读数与业务示例值仍按1%吸附。抓取时记录当前视觉位置，不因点击旋钮其他位置而跳值；拖动事件合并为每帧绘制，松手短距离平滑吸附。跨过底部角度边界时累计相对角度，不从100突然绕回0。
3. 键盘和精确输入引起的旋钮转动使用临界阻尼运动，新目标继承当前视觉位置与速度，避免从旧起点重播。开关保留220ms缓动，连续反向操作从当前位置继续。
4. 数字默认约280ms逐位滚动。连续点击全部更新目标值；当前滚动结束后合并到最新目标，不忽略后续点击，也不逐次排长队。完成后一次替换静态数字并释放动画对象。
5. 卡片拖动使用逐帧位置更新，回位使用临界阻尼衰减；回位途中再次抓取从当前可见位置接手。详情展开仍在预留区域完成，避免推挤其他模块。

支持系统减少动态效果与评审复选框，切换时停止正在运行的运动；减少动态后仍保留正确数值、开关和展开状态。评审调节面板仅保留“节奏基准”，不在本轮引导用户更换配色或材质。
