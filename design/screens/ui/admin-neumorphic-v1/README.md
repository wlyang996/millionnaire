## 设计范围

保留“大富翁”品牌与现有功能，提出浅灰新拟物布局：左侧实体键帽导航，顶部轻量状态区，中间按任务组织工作区。工作台展示机械数字、趋势和抽拉待办；声音工作室展示旋钮、拨动开关和场景绑定。整页图用于评审视觉与布局，不能证明动画手感。

“新礼物”按“新拟物”理解；用户末句按“只给按下状态和关键数据使用强调色”处理。冷浅灰基础色，左上白色与右下灰紫两层柔和阴影，24px大圆角。紫色用于当前导航与主操作，青色用于音乐，玫红用于音效，琥珀用于循环与提醒。状态同时包含文字、图标和颜色。

## 五类交互建议（待评审）

1. 实体按键：默认凸起，悬停上浮2px；按下下沉1px，外阴影切换内阴影；120ms按压、220ms回弹；当前项持续凹入并点亮指示灯。分组可折叠，长菜单独立滚动。
2. 旋钮：音量0～100，吸附步长1，主刻度每10显示；拖动、键盘方向键、直接数字输入并存。外圈亮弧、数值、图标及试听同步。其他参数沿用真实服务端范围和步长；只有存在明确目标值的图表才联动目标线。
3. 拨动开关：只映射已有业务布尔项或明确的本机偏好。音乐、音效总开关置于各自卡片右上；开启后滑块吸附回弹、LED亮起、图标转为模块色；关闭反向渐暗。保留只读、禁用与焦点状态。
4. 机械数字：每位独立滚动，280～420ms结束并轻微过冲；减少动效模式直接更新；高频采样合并更新。加载中、零值和不可用分别呈现，位数变化保持布局稳定。
5. 抽拉卡片：待办和版本卡片叠放，独立拖动手柄；下拉达到72px展开详情，不足则归位；后方卡片错峰下沉回弹。点击、回车和“查看详情”按钮执行同一操作。抽拉不触发审核或发布。

时间和阈值为视觉交互建议，不是新增玩法参数，接入前按真实页面空间和可用性评审调整。
