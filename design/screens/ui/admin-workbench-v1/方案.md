# 我的工作台与全局命令面板

2026-10-14，用户确认生成方案并实现。延续现有 Vue 3 彩光游戏控制台，复用 SpotlightCard、BorderBeam、NumberTicker 和页面入场动效。

## 首页布局

登录后进入“我的工作台”，完整数据看板仍单独保留。全景模式采用六列 Bento 布局：大幅快捷出发区、编辑提醒、三间工作室、统计脉搏、收藏入口、最近访问及玩法发布动态。聚焦模式展开主要区域，收藏入口更宽。手机按单列排列。

工作室分别采用紫、青、玫瑰色强调，显示载入的玩法版本、生效人物目录和音频版本。编辑提醒明确区分当前会话修改与服务端素材草稿。玩法发布动态提供折叠记录与历史版本对比入口。

收藏可通过页面右上角星标或首页入口添加，最多12项，按钮调整顺序；最近访问保留8项，首页显示最近5个其他页面。收藏、访问和布局在本机按后台用户ID隔离保存，权限变化后立即过滤不可访问项，退出后清空内存中的账号偏好。

## 动效与操作

快捷出发区使用彩光轨道、浮动游戏核心与三个工作室节点；工作室卡片响应鼠标光斑与轻微倾斜，统计数值递增，真实每日对局柱形入场，收藏排序平滑移动。复用原有主题揭幕、侧栏共享选中态、发布庆祝与页面入场。

遵守丰富、标准、简化动效和系统减少动态效果偏好；页面隐藏时暂停轨道循环，触摸设备保留普通点击，避免依赖悬停。

## 全局命令面板

顶部按钮或 Ctrl+K / Command+K 打开。支持页面中文名、描述、英文ID和参数中文名/路径搜索，空查询优先收藏与最近访问，搜索词高亮。上下键选择、Enter打开、Esc关闭，兼容中文输入法组合输入。

参数结果切换到所属页面，定位并临时描边对应字段；动态重复字段或只读摘要找不到精确字段时定位页面。导航保留原有参数、人物和音频编辑草稿。安全快捷操作仅切换主题和动效级别；发布、回滚、改密、账号授权仍由现有页面及确认流程处理。已有确认弹窗打开时，不由全局快捷键抢焦点。

## 数据与权限

使用现有 dashboard、config、characters、audio API，无新增玩法参数和数据库迁移。指标明确标注统计时间范围、北京时间及人次口径，未连接数据库时展示不可用状态。工作室请求可独立失败和重试，失败不显示成功状态。

人物、音频具有草稿权限的角色读取管理状态，否则只请求 /published；所有页面、收藏、最近访问、命令结果均按服务端返回的权限过滤，401/403沿用公共会话处理。取消或过时请求的结果不得写回已经离开的工作台。

## 交付范围

本批完成工作台、命令面板、个人入口管理和配套动效。波形编辑、实时房间控制台及高级版本时间线属于后续功能，不混入本批。构建产物随源代码提交；按用户最近指示仅本地提交，由用户推送。
