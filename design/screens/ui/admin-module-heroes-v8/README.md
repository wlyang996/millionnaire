## 从当前实现看到的问题

本地AdminShell.vue的页面横幅共用渐变、hero-aurora和Orb/静态圆形效果，公告、地图、人物、声音等模块主要替换文案和强调色。control-colors.css将模块强调色与深色基底混合，公告的琥珀色会呈现偏棕的大面积色块；源码结构与用户截图的“棕色横幅＋单个光环”表现一致。

桌面hero-orb为190px，上下padding合计64px，横幅的内容约束会撑高首屏。仅调整min-height并不能解决占位问题，后续需要同时调整右侧场景尺寸与留白。此为本地CSS分析，未测量线上布局或核对部署版本。

## 补充方向

保留已确认的白色面板、浅灰背景、原版彩色线性菜单与任务布局。顶部横幅改为浅色信息区：左侧保留标题、说明与真实编辑状态，右侧放一个与当前模块有关的小场景，避免继续用同一个光环换色。

首批四种场景：

- 公告管理：喇叭、公告卡片、小镇发布台，让画面表达“告诉玩家”。
- 地图与经济：微缩棋盘角、房屋、棋子与一枚金币，表达地图和地产规则。
- 声音工作室：耳机、唱片与唱片套，表达音乐制作；不增加装饰性仪表或伪造播放数据。
- 人物工作室：角色卡框、抽象棋子和画笔，表达素材创作；插画不代表新增或已发布的人物皮肤。

其余模块可按相同语言扩展：玩法规则用骰子与事件卡，版本中心用版本卡片与时间标记，账号管理用钥匙与盾牌。该扩展仅是方向，不表示本轮已交付全部模块素材。

## 布局与动效建议

桌面横幅建议约190～210px高，文字占约60%～65%，场景集中在右侧；长标题允许自然增高。手机优先保留标题和操作区，场景缩小或隐藏。背景保持白色与极淡模块色，颜色集中在场景小物件上，不重新使用米黄底或整块深色背景。

动效延续顺滑节奏：可在进入模块时，让公告卡片轻滑就位、唱片轻转后停、角色卡轻叠入。文字与表单保持稳定；不持续大幅漂浮，不做满屏粒子，不用闪烁制造热闹。仍须遵守已有动效偏好、系统减少动态效果和页面不可见暂停逻辑。静态设计图不能证明这些动效已实现或验证。

插画不新增业务按钮、指标或发布步骤，dirty提示仍由真实编辑状态驱动。图表只服务运营问题与配置校验，此横幅不堆统计图。
