## 工作台保留什么

- 待我处理：直接展示需要当前账号处理的发布请求，进入详情；不为待审核数量额外建一张大指标卡。
- 继续编辑：展示未发布草稿并提供明确入口，不添加无业务定义的完成率。
- 当前生效：用紧凑列表列出规则、人物、音频的生效版本，进入发布记录；不重复铺三个大版本卡。
- 常用入口：玩家查询、历史对局、实时房间、素材管理，按权限展示。

移除首页趋势图、装饰性迷你折线、三张大数字指标和孤立的试听音量旋钮；不给首页硬塞五类控件。卡片抽拉用于待办详情，旋钮和开关放到声音设置等有对应参数的位置。机械数字只用于需要持续观察的真实数值，更新频繁时不得干扰输入和阅读。

## 图形使用原则

图表必须回答具体问题：例如数据看板的真实对局趋势、规则编辑时的概率分布。必须有明确的数据来源、指标含义、时间范围或配置含义；能用一行状态或列表说清楚的，不画图表。声音工作室的波形直接用于试听定位和区间选择，应保留，不视为装饰性统计。

数字、版本、人员和时间均是构图示例，示例图不代表生产状态。落地时从现有接口获取当前账号可见的数据，缺少数据时按功能语义显示真实空态，不补造数值，不使用无意义占位图表。
