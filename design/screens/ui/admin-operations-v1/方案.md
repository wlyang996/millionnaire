# 管理端运营工具补齐 · v1

用户范围：完成规则自动草稿、规则备份、实时房间、音频试听工具、人物与音频历史对比五项。本地提交，由用户自行推送。

## 规则草稿与备份

在规则页及版本中心上方设置统一工具条。规则编辑按后台账号 ID 保存到本机，记录参考版本、原始配置、编辑数值及未提交的逗号输入文字。离开、切换后台账号、退出前及时保存。再次进入只提示发现草稿，不自动覆盖当前配置；先比较，再恢复。参考版本变化时明确提醒。

导出为有格式版本号的 JSON 包，包含参考规则版本及导出时间。导入限制 2MB，拒绝危险字段与错误格式，调用原有后台配置校验，再展示相对当前编辑区的变化。确认只载入编辑草稿，沿用原有校验、审阅与发布流程。未提交的输入文字单独列出并原样恢复，发布前仍须完成输入与校验。

## 实时房间

导航位于运营总览，使用 `dashboard:read`。五张统计卡展示活跃房间、进行中、参与人数、托管和观战人数。提供房间号、状态筛选，分页及手动/5/10/30 秒刷新。详情显示地图、模式、轮次/回合、对局编号、规则与人物版本、时间。

数据来自当前服务实例内存中的真实房间，不把数据库 OPEN 记录当作实时状态。人数包含本局参与者与机器人，不等于在线人数。页面隐藏时停止轮询；采样失败保留上次结果并提示。接口无写操作，不读取玩家身份、手牌、余额、随机状态等私有数据。

## 音频试听工作室

复用当前资源试听，新增场景选曲入口，使用实际 WAV 在本机解析波形。显示播放位置，支持点击波形及左右键定位，开始/结束秒数和循环试听。区间仅用于本机试听，不写入草稿或游戏配置。加载不自动播放，离页或页面隐藏时停止。解析不支持或失败时保留原生音频控件。

## 已发布媒体历史对比

人物按稳定 ID 对齐，比较新增/移除、名称、排序、启停、备用人物及七张基础素材和四张移动姿态。图片依据摘要/URL/内置身份识别变化，左右并排展示已有真实素材及缺失状态。

音频比较开关、默认音量、淡入淡出、各场景绑定/循环及各独立音效绑定，显示资源名称和静音状态。两个历史接口只返回已发布版本及必要资源信息，观察员可查看，不能读取草稿；查看对比不覆盖正在编辑的内容。

视觉沿用现有彩光控制台、主题与动效偏好，不引入新第三方组件包、不调整已采用人物素材或玩法参数。
