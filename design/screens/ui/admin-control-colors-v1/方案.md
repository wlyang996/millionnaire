# 管理端控件与模块配色

2026-10-14，按用户“不能只用一个颜色，整体看一下”的反馈，补齐工作台之外的表单、导航、详情页和统计卡片。

采用六组稳定强调色：紫用于工作台与起点抽卡；蓝用于房间设置、分组和版本；青蓝用于声音、城市事件与操作时限；玫红用于人物、概率和称号；琥珀用于价格、金额、轮次奖励与公告；绿色用于实时运行、队伍与土地命名。导航分组图标分别着色，每个页面的选中态、标题、焦点和主操作颜色保持一致。

音频页进一步区分功能：音乐使用青蓝，音效使用玫红，循环和淡入淡出使用琥珀，播放及发布使用绿色。两个声音通道保留名称、图标与说明，增加各自的背景、边框、开关和音量条；不能仅依赖颜色区分功能。试听波形根据资源用途着色。

实时房间和数据看板分别采用五色指标；四组概率预览保持各自的图表分类色，并增加奖池卡片强调色。成功、警告、错误和信息保留原有语义，不随页面强调色改变。

浅色主题使用较深的强调色保证文字可读；深色主题使用更明亮的强调色，并同步按钮文字、开关滑块、单选和复选标记、状态提示的背景。窄屏将声音通道改为单列；保留现有动画偏好、权限、输入绑定和发布流程。

配色在 CSS 中集中维护，页面及功能使用明确的色组标记；浮层沿用当前页面的全局主题。此处为管理工具视觉样式，未新增玩法参数或修改游戏音量默认值。
