后续 v6：用户要求道具栏单排默认可见五项、多项横滑；土地名纳入地图 UI；本局倒计时低于十分钟变红、低于三分钟红色闪烁。见 `../board-v6/README.md`。本版四列两排玩家状态栏继续保留。

用户指出每排三人时，八人需要第三排，会挤占棋盘。最新设计改为紧凑的四列：最多八人，两排显示；保留每人的头像、昵称与金币。右侧放大、缩小、“定位我”按钮仍按 v4 的确认取消。人物本身的“我”标记保留。

## 布局建议

- 两至四人使用一排，五至八人最多两排，不出现第三排。
- 头像在卡片左侧，昵称与金币在右侧上下排列；统一缩小头像、内边距和装饰，不只缩小文字。
- 本人保留蓝色“我”标记，当前行动者用细金色高亮边区分；未给所有玩家都加醒目边框。
- 昵称只在状态卡上按空间省略，完整昵称在玩家详情显示，不改变昵称校验规则。
- 以 720px 设计宽度为建议参考：头像约 40–44px，卡片高度约 60–68px；具体字号和间距需按手机实际显示校准，图片不是像素规范。
- 缩小状态栏及其与棋盘之间的空白，把节省的高度留给棋盘，底部道具栏和资产栏保留。
