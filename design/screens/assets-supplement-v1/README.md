# 透明位图补充包

日期：2026-10-06。输出路径：design/screens/assets-supplement-v1/。状态：已拆分85个透明PNG的候选，未导入或测试Cocos。分类索引见[MANIFEST.md](MANIFEST.md)。

本轮由内置image_gen生成11类原生透明图集。用户明确允许PIL清理后，保存85个单件到png/，清除alpha杂点和邻格残片；atlases/原图不覆盖，raw/保留纠错前稿。不是整页截图放大。previews/保留各类透明棋盘格背景预览，已逐类查看。

类别：8头像、8全身棋子、0–3级房屋、干净中央小镇、6按钮底、20图标、14道具卡及通用卡底/卡背、6点骰子及3翻滚帧、鳄鱼开/半闭/闭口、牙齿正常/按下、5种事件正面与卡背/展开牌堆/提示框。

使用约定：文字、昵称、金币数、倒计时由游戏文字层绘制，按钮和卡面下部留空；事件卡牌堆与中央卡背共享造型。危险牙使用同一个正常牙图，不能提前视觉区分。翻滚帧只是位图姿态，运行时骰子与逐格跳跃仍需要程序动画。

manifest.json的等分格是原始诊断索引；实际单件源区域、裁切偏移、8像素透明留边、清理参数和SHA-256见sprites.json。跨格房屋／卡牌已扩大裁切范围，牌堆已排除邻格提示框。导入时须校准SpriteFrame、缩放、鳄鱼牙齿锚点、按钮九宫格；尚未验证引擎导入。

split_clean.py为用户授权的PIL拆分清理脚本，不重绘RGB主体，保留主体alpha及抗锯齿；inspect_atlases.py仅检查原稿元数据，不改像素。

完整内置 image_gen 提示词见 ../ui/supplement-v1/jobs.json。历史素材包 assets/、assets-v2/、assets-v3/ 保留，不覆盖。
