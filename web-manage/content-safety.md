# 昵称与聊天内容检测

2026-10-13：已接入保存前与广播前检测。后台「数据看板」显示启用状态及接入说明；`GET /admin-api/v1/content-safety` 需要统计查看权限，不返回用户内容或身份。

## 微信云托管配置

- 云托管「云调用」为实际 Java 服务放行 `/wxa/msg_sec_check`，并开启开放接口服务。沿用已有微信登录配置；不新增长期密钥或向客户端传递 token。
- 设置 `CONTENT_SAFETY_ENABLED=true`。超时由 `CONTENT_SAFETY_TIMEOUT_MS` 配置，范围1000～10000毫秒，默认4000。
- 该开关是部署级安全策略，默认关闭用于现有本地测试；关闭时聊天明确记为 `UNCHECKED`，绝不标为已检测。后台显示配置状态，不把启用标签当作接口可用性证明。

使用官方微信云托管内部开放接口地址，version=2，昵称scene=1、聊天scene=2。昵称身份取微信登录交换的openid；聊天身份从服务器账号关联取得，忽略客户端openid与检测结果。没有微信身份的测试用户在开启检测后不能提交昵称或聊天。

仅 `errcode=0` 且 `result.suggest=pass` 允许继续；risky、review、未知结果、超时、接口拒绝或响应损坏均拒绝本次内容。拒绝昵称不创建/更新用户；拒绝聊天不广播、不落库、不消耗成功聊天间隔。客户端保留失败消息的输入文字。关闭检测与通过检测分别保存UNCHECKED/PASS，不伪造结果；旧记录保持原状态。

外部请求在房间锁外执行，回来后重新验证成员和房间状态。接口不记录文本、openid、原始响应或凭证。响应限制32KB、不跟随重定向。没有离线关键词替身冒充微信检测，也没有自动放行失败内容。

微信云托管官方示例：[TCloudBase开放接口服务](https://github.com/TCloudBase/wxcloudrun-wxapidemo-auto)。该示例明确需要放行 `/wxa/msg_sec_check` 并支持免令牌的开放接口服务。本机测试使用HTTP替身及真实HTTP/WebSocket接线，实际微信账号能力、云调用权限和真实平台返回需部署后验收。
