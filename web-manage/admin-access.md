# 后台账号、权限、会话与审计

本版本将共享密码升级为独立后台账号。游戏玩家微信登录不变。后台旧令牌和仅带password的旧登录请求不再有效；旧ADMIN_PASSWORD不再参与后台鉴权。

## 上线前准备

1. 先确认独立音频任务的V6迁移已纳入同一部署版本或已在数据库执行，再上线本版本V7。当前功能分支没有复制未提交的音频源码或V6脚本。不能先执行V7、以后才补低版本V6；也不要用Flyway repair或临时开启outOfOrder掩盖顺序问题。
2. 生产启用db profile并确认MySQL连接有效。本地无库演示必须显式设置ADMIN_ALLOW_IN_MEMORY=true，生产保持false；数据库故障不会降级成内存或共享密码。
3. 在云托管服务环境变量配置ADMIN_BOOTSTRAP_USERNAME（3～32位规范账号，例如admin.root）和ADMIN_BOOTSTRAP_PASSWORD（你设置的强密码）。密码至少12个字符，最多64个字符，UTF-8最多72字节，不含控制字符。禁止把真实密码写入仓库、命令行参数或提交说明。
4. 空账号表首次登录时创建超级管理员，并要求改密。完成改密后用新密码重新登录，再移除初始化密码变量。账号表非空时，环境变量不会覆盖现有账号或恢复停用账号。
5. 推送prod可能触发重新部署并解散进行中的对局。部署后验证首次改密、超级管理员可管理账号、只读/运营无法越权及日志关联，再撤除旧环境变量。

未配置初始化变量时游戏接口仍可运行，后台明确返回初始化未完成。初始化不创建默认弱密码，不提供共享密码后门。

## 固定角色

- 超级管理员：内容读写、上传、发布与回滚；账号管理；撤销其他账号会话；查看审计。
- 运营管理员：统计和内容查看，编辑、上传及发布；没有回滚、账号管理和全局审计权限。
- 只读观察员：统计、生效规则、生效人物与规则历史对比；不能读取人物草稿、编辑、上传或发布。

所有角色均有本人密码修改和本人会话管理。人物只读页面通过独立published接口读取，响应不含packs或对象存储状态。音频在其独立任务合入后接入明确权限声明；未知管理接口默认拒绝。

规则与公告属于整份配置，不能把运营权限理解为“只能修改公告”。菜单和按钮随permissions显示，后端再次检查，不接受请求体中的操作者身份。历史created_by=admin显示“历史共享管理员”，新版本保存实际不可变用户名；人物新版本通过审计显示发布人，旧记录显示“未记录”。

## 常用操作

系统管理 → 后台账号：搜索、分页、新增、修改姓名/角色/状态、重置密码和查看会话。账号创建后不能修改用户名，不提供账号删除。角色/状态变更带expectedVersion，过期编辑409后需刷新核对。

临时密码仅在创建或重置成功后显示一次，关闭抽屉后不会再次查询。首次登录必须改密。管理员本人不能使用“重置密码”跳过当前密码校验，应从个人菜单改密。最后一个启用的超级管理员不可停用或降级，包含并发请求。

个人菜单 → 我的会话：查看登录设备、绝对到期时间和近期活动，退出当前设备或撤销其他本人的会话。默认12小时，可并存设备；最多保留20个有效设备会话，登录新设备时撤销更旧的超额会话。活动时间按分钟更新，不表示实时在线。退出、停用、降权、改密或重置后的旧令牌下一请求失效。

系统管理 → 操作审计：按账号、动作、结果及时间筛选、分页、查看请求编号和脱敏摘要。规则成功发布记录可转到版本中心选择相关版本对比；不能修改、删除或导出日志。密码、哈希、令牌、上传文件内容和完整请求体不会记录。

## 安全配置

ADMIN_SESSION_HOURS默认12；ADMIN_MAX_FAILURES默认5；ADMIN_LOCK_MINUTES默认5；ADMIN_IP_ATTEMPTS默认30；ADMIN_IP_WINDOW_SECONDS默认60。BCrypt成本ADMIN_BCRYPT_STRENGTH默认12，允许4～16，生产先测容器成本，不使用测试的低成本配置。

ADMIN_TRUSTED_PROXIES为明确的代理地址列表，默认不信任转发来源。校验来源会拆开框架包装并从实际连接地址起判断代理链，不直接信任客户端自带的X-Forwarded-For。生产需根据真实代理链核对配置，不填通配符。

令牌仍在浏览器sessionStorage，仅同源Bearer请求使用；服务器只存SHA-256令牌摘要。改成Cookie或单点登录需要另行设计相应保护，本版本不提供这些入口。

## 运维恢复

只提供独立CLI，HTTP没有公开恢复接口。维护人员在可信运行环境、启用db profile和数据库权限的前提下设置ADMIN_RECOVERY_USERNAME及ADMIN_RECOVERY_PASSWORD，然后显式运行：

```powershell
java '-Dloader.main=com.millionnaire.gateway.admin.AdminRecoveryMain' -cp target/app.jar org.springframework.boot.loader.launch.PropertiesLauncher --confirm-admin-recovery
```

恢复目标须为已有账号，恢复为启用超级管理员，撤销全部会话并要求首次改密；记录offline-recovery审计。完成后移除恢复密码环境变量。CLI需使用本版本包；不要把普通代码回滚到共享密码版本视为安全等价恢复。

## 验证边界

本地H2 MySQL模式执行V1～V5和V7，验证身份、权限、事务、撤销和最后管理员保护。迁移V6属于其他任务，上线前必须核对其版本与执行顺序。真实MySQL5.7、实际代理链、多实例部署、真实COS与生产上线仍需目标环境验收。实施及页面记录见design/screens/records/admin-access-implementation-2026-10-13/交付记录.md。
